# Incastro Turni – download e aggiornamenti

App per creare i turni mensili del reparto: desiderata, regole, generazione automatica, PDF da approvare.
Questo repository contiene solo le versioni installabili; l'app si aggiorna da sola.

**Sito, guida e video: <https://acaland.github.io/incastro-turni-releases/>**

## Scarica l'ultima versione

| Computer | File da scaricare |
|---|---|
| **Windows** 10/11 | [IncastroTurni-win-x64-Setup.exe](https://github.com/acaland/incastro-turni-releases/releases/latest/download/IncastroTurni-win-x64-Setup.exe) |
| **Mac con Apple Silicon** (M1, M2, M3, M4…) | [IncastroTurni-osx-arm64-Setup.pkg](https://github.com/acaland/incastro-turni-releases/releases/latest/download/IncastroTurni-osx-arm64-Setup.pkg) |
| **Mac con processore Intel** | [IncastroTurni-osx-x64-Setup.pkg](https://github.com/acaland/incastro-turni-releases/releases/latest/download/IncastroTurni-osx-x64-Setup.pkg) |

Non sai che Mac hai? Menu  → Informazioni su questo Mac: se alla voce «Chip» c'è «Apple M…» è Apple Silicon.

## Installazione (non servono permessi di amministratore)

**Windows** – apri il file scaricato. Se compare «Windows ha protetto il PC», clicca
*Ulteriori informazioni* → *Esegui comunque*. L'app si installa da sola e compare nel menu Start.

**Mac** – apri il file `.pkg`, prosegui e, alla scelta della destinazione, seleziona
*Installa solo per me*. Se il Mac blocca l'apertura: Impostazioni di Sistema → Privacy e sicurezza →
*Apri comunque*
(su macOS 15 e successivi premi prima *Fine* nell'avviso, poi *Apri comunque*).

## Aggiornamenti

Automatici: l'app controlla le nuove versioni all'avvio e ogni qualche ora, le scarica e le installa
al riavvio (o subito con «Riavvia e aggiorna»). I dati restano sul computer e non vengono toccati.

## I tuoi dati

Medici, regole e turni stanno solo sul tuo computer. Per passare a un altro PC: nell'app,
Impostazioni → *Esporta archivio*, poi sull'altro PC *Importa archivio*.
